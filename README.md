# Телеграм-планировщик для дочери

Telegram-бот + веб-панель для родителя. Родитель управляет расписанием уроков
и домашними заданиями через простую веб-панель (браузер), а бот сам
присылает дочери напоминания в Telegram.

## Возможности

- **Расписание уроков** — недельная сетка (день недели, время, предмет, кабинет, учитель).
- **Домашние задания** — список с дедлайнами и отметкой «выполнено».
- **Автоматические напоминания** дочери в Telegram:
  - утренняя сводка (расписание + ДЗ на сегодня) в заданное время;
  - напоминание за N минут до каждого урока;
  - напоминание в день сдачи ДЗ и заранее (за N дней до дедлайна).
- **Команды в боте** для дочери: `/today`, `/week`, `/homework`, `/help`.
- Веб-панель защищена логином/паролем — доступна только вам.
- Привязка бота к аккаунту дочери — по одноразовому коду, который вы
  генерируете в веб-панели (случайные люди подключиться не смогут).

## Как это устроено

Один Python-процесс запускает сразу три вещи:
1. Telegram-бот (polling, `aiogram`).
2. Веб-панель (`FastAPI`, на порту 8000 по умолчанию).
3. Планировщик, который раз в минуту проверяет, не пора ли отправить
   напоминание (`APScheduler`).

Данные хранятся в SQLite-файле `data/bot.db` — отдельная база данных не нужна.

## Быстрый старт (локально, для проверки)

1. Создайте бота через [@BotFather](https://t.me/BotFather) командой
   `/newbot` и получите токен вида `123456789:AA...`.
2. Установите Python 3.11+ и зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните:
   ```bash
   cp .env.example .env
   ```
   - `BOT_TOKEN` — токен от BotFather.
   - `ADMIN_USERNAME` / `ADMIN_PASSWORD` — логин и пароль для входа в веб-панель.
   - `SESSION_SECRET_KEY` — любая длинная случайная строка.
   - `TIMEZONE` — например, `Europe/Moscow` (можно поменять позже в настройках).
4. Запустите:
   ```bash
   python run.py
   ```
5. Откройте `http://localhost:8000` в браузере, войдите под `ADMIN_USERNAME`/`ADMIN_PASSWORD`.
6. В разделе **Настройки** нажмите «Сгенерировать код привязки» и передайте
   код дочери — она открывает бота в Telegram и отправляет `/start КОД`.
7. Заполните расписание и домашние задания — напоминания начнут приходить
   автоматически.

## Куда деплоить (варианты, раз вы ещё не решили)

Бот должен работать постоянно (24/7), поэтому «запустить на своём ноутбуке»
подходит только для теста. Варианты для реальной эксплуатации:

- **Простой VPS (рекомендую)** — например, Timeweb, Selectel, Hetzner,
  DigitalOcean (от ~$4–5/мес). Самый предсказуемый и дешёвый вариант,
  полностью под вашим контролем. На сервере:
  ```bash
  git clone <ваш форк репозитория>
  cd rep
  cp .env.example .env   # заполните токен, логин/пароль, секрет
  docker compose up -d --build
  ```
  Бот и веб-панель поднимутся в Docker-контейнере и продолжат работать после
  перезагрузки сервера (`restart: unless-stopped`).

- **Railway / Render / Fly.io** — есть бесплатные/дешёвые тарифы, деплой из
  Git-репозитория без своего сервера. Проще в настройке, но бесплатные
  тарифы иногда «усыпляют» процесс — для бота с напоминаниями это плохо,
  нужен платный «always-on» план.

- **Домашний компьютер / Raspberry Pi** — бесплатно, но должен быть постоянно
  включён и с интернетом; для веб-панели снаружи дома понадобится проброс
  порта или туннель (например, Cloudflare Tunnel).

Если решите — скажите, и я подготовлю пошаговую инструкцию именно под
выбранную площадку (например, конкретные команды для Railway или systemd-unit
для VPS без Docker).

## Структура проекта

```
app/
  bot/bot.py        — обработчики команд Telegram-бота
  web/server.py      — веб-панель (FastAPI) и HTML-шаблоны
  web/templates/      — страницы веб-панели
  models.py           — таблицы БД (Student, Lesson, Homework, PlannerSettings, ReminderLog)
  reminders.py         — логика проверки и отправки напоминаний (запускается раз в минуту)
  services.py, formatting.py, constants.py — общие утилиты
run.py                 — точка входа: запускает бота, веб-панель и планировщик вместе
```

## Безопасность

- Веб-панель закрыта логином/паролем из `.env` — обязательно поменяйте
  значения по умолчанию.
- `.env` и файл базы данных (`data/`) не должны попадать в git — они уже
  добавлены в `.gitignore`.
- К боту в Telegram может подключиться только тот, кто знает код привязки,
  который видите и генерируете только вы в веб-панели.

## Автоматический бэкап базы данных

Скрипт `scripts/backup_db.sh` делает безопасную «горячую» копию
`data/bot.db` (через `sqlite3 .backup`, поэтому не повреждает файл, даже
если бот в этот момент пишет в базу), сжимает её и хранит последние
14 дней (настраивается через `KEEP_DAYS`), удаляя более старые копии.

Настройка автозапуска на сервере (systemd-таймер, запуск раз в сутки в 03:30):

```bash
# sqlite3 CLI нужен на хосте (не в контейнере) — скрипт запускается снаружи
apt install -y sqlite3

# если склонировали репозиторий не в /root/bot — поправьте путь
# в scripts/systemd/bot-backup.service (ExecStart)
cp scripts/systemd/bot-backup.service /etc/systemd/system/
cp scripts/systemd/bot-backup.timer /etc/systemd/system/

systemctl daemon-reload
systemctl enable --now bot-backup.timer
```

Проверить, что всё настроено и когда следующий запуск:
```bash
systemctl list-timers bot-backup.timer
```

Запустить бэкап вручную (не дожидаясь 03:30) и посмотреть лог:
```bash
systemctl start bot-backup.service
journalctl -u bot-backup.service -n 20
```

Бэкапы лежат в `backups/` рядом с проектом. Это защищает от повреждения
базы или случайного удаления, но не от полного отказа диска/сервера —
для более надёжной защиты стоит время от времени копировать содержимое
`backups/` куда-то ещё (на свой компьютер, в облако и т.п.), например
`scp` или `rclone`.
